Compilateur en Assembleur

Développement d'un compilateur pour traduire le code assembleur en code machine.

Description
Ce projet consiste à développer un compilateur en langage assembleur capable de traduire des instructions assembleur en langage machine exécutable. Le compilateur prend en charge les opérations de conversion et d'optimisation du code source.

Date: Février 2025

Technologies: Assembleur, C++, Algorithmes de compilation
